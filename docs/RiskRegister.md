# Risk Register



| ID   | Risk                                                         | Likelihood | Impact | Mitigation Strategy                                          |
| ---- | ------------------------------------------------------------ | ---------- | ------ | ------------------------------------------------------------ |
| R1   | Team member unavailable or delays in task completion         | Medium     | High   | keep update RACI, maintain regular communication             |
| R2   | Scope creep (adding too many features)                       | High       | High   | Define clear MVP, use MoSCoW prioritization, require team agreement for changes |
| R3   | Limited or unreliable API data (price, product info)         | High       | Medium | Use simulated dataset, design system to handle incomplete data |
| R4   | Technical challenges in route optimization algorithm         | Medium     | High   | Simplify algorithm, focus on core functionality, allocate buffer time |
| R5   | Time constraints before deadline                             | High       | High   | Build timeline with buffer, prioritize must-have features    |
| R6   | Git conflicts and version control issues                     | High       | Medium | Pull before push, use small commits, use rebase, assign merge responsibility |
| R7   | Inconsistent requirements across sections                    | Medium     | High   | Perform cross-check reviews, maintain shared document standards |
| R8   | Poor usability (users cannot complete tasks easily)          | Medium     | High   | Conduct user testing, refine UI based on feedback            |
| R9   | Data anomalies (empty input, missing data) causing system errors | Medium     | Medium | Implement error handling and validation mechanisms           |
|      |                                                              |            |        |                                                              |
|      |                                                              |            |        |                                                              |
